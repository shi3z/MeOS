# Writing editor

Tab5 shell: `write [FILE.txt]` (default `note.txt` in the current directory).
Simulator: `sh tools/sim/run.sh --write --workspace DIR --source /home/note.txt`.
Create DIR first; host files are confined to this workspace. F12 captures a BMP
when `--screenshots DIR` is provided.

BIZ UD Gothic Regular is rendered from its original TrueType outlines at 24
native pixels by default on a warm light page. F3/F4 switches live between
20, 24, 28 and 32px; the document, vertical columns, cursor, preedit and
candidate popup are reflowed together. If the TTF is absent or invalid, Write
falls back to the fixed 24px atlas and leaves size switching disabled.
The only editor chrome is a single line at the top containing the writing mode,
modified mark, essential shortcuts, IME state, transient status and path (in
that order, so a long path is clipped first). The document begins immediately
below it and extends almost to the bottom edge. A vertical column fits 21 normal
full-width characters; horizontal mode displays 18 lines.
Write opens in Japanese vertical prose mode: text flows down from the upper
right and subsequent columns advance left, with 6px character tracking and a
40px column pitch. BIZ UD's OpenType `vrt2` alternates and vertical metrics place
punctuation, brackets, long vowels, small kana and rotated Latin correctly.
Closing marks may hang into the lower margin, while opening and closing brackets
receive a bounded Japanese line-start/line-end prohibition pass. This is not a
full JLREQ layout engine.

Ctrl-T switches immediately to proportional horizontal layout; line and column
pitch follow the selected size. In vertical mode Up/Down moves within a column and Left/Right
moves between columns; Home/End select its top/bottom. MeOS IME preedit is
inserted at the document cursor in either direction, reflowing following text
without entering the file. Its two-column candidate popup remains horizontal
beside the active column. Ctrl-Space toggles the IME; Space converts and Enter
commits. Ctrl-S saves, Ctrl-Q exits (repeat to discard unsaved edits), and Ctrl-Z
undoes the last edit. An entire confirmed IME conversion is inserted atomically,
so it takes one buffer update, one repaint and one undo step instead of one of
each per character. PgUp/PgDn navigate a screenful. Buffer limit 16 KiB, one
undo snapshot. UTF-8 files and MeOS VFS are used.

Only BIZ UD is used. On Tab5, Write first opens
`/assets/fonts/BIZUDGothic-Regular.ttf` through FreeType with a 16-way 16 KiB
VFS stream cache. Documents of at least 8 KiB with 256 distinct non-ASCII
characters open the face from a 4.67 MiB PSRAM copy; allocation or I/O failure
falls back to the stream face. This avoids a nine-second full
font read for ordinary notes while eliminating repeated random microSD reads
for diverse long-form text. The SD-root asset path can satisfy sequential font
reads from two 64 KiB windows and repeated littlefs traversal from a 1 MiB
four-way sector cache; it falls back to direct I/O if PSRAM is unavailable.
`mem trim` releases that optional cache, and a failed Write/FreeType PSRAM
allocation also releases it before retrying the required editor allocation.
The bounded 384-glyph 4-bit cache and font source
are released on exit. A separate four-way metrics cache lets full
document layout obtain advances without rasterizing off-screen glyphs. The
pinned `vrt2` codepoint-to-glyph map is
generated by `tools/fonts/build_otfont_vertical.py`; vertical advances still
come from the font at the selected size. Missing glyphs show a box.
Combining marks and IVS are not shaped as sequences yet. The atlas contains
11,741 ordinary cmap glyphs and 350 Unicode-addressable `vrt2` alternates and is
about 2.35 MiB. It remains the simulator renderer and Tab5 fallback. Its
vertical index is a CRC-covered version-1 extension, so an older OTA image can
still load and use the ordinary bank;
a full offscreen RGB565 frame (about 1.76 MiB) is also allocated in PSRAM to
avoid clear/redraw flicker. The framebuffer is released on exit. Scheme still
uses the fixed atlas, which can remain warm until `mem trim` or Home opens a
non-editor. The same BIZ UD IME presentation code is shared by both editors.

`sh tools/sim/write_test.sh` replays the real MeOS IME through HID input, saves
Japanese text, verifies exact UTF-8 file contents, captures vertical composition,
verifies phrase-granular undo, and checks that Ctrl-T produces a distinct
horizontal frame.
